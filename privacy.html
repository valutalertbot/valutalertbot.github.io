Политика конфиденциальности ValutBot

Последнее обновление: 9 августа 2026 г.

Настоящая Политика конфиденциальности объясняет, какие данные обрабатывает ValutBot («ValutBot», «Сервис»), для каких целей они используются, как долго хранятся, кому могут передаваться и какие права имеет пользователь в отношении своих персональных данных.

ValutBot доступен в том числе через платформу Telegram. Telegram является отдельным сервисом и самостоятельно обрабатывает данные пользователей в соответствии со своими условиями и политикой конфиденциальности.

1. Данные Telegram-профиля

При взаимодействии с ValutBot Сервис может получать и хранить:

  • Telegram ID пользователя;
  • username, если он установлен и доступен;
  • отображаемое имя, если оно доступно;
  • язык;
  • часовой пояс;
  • дату регистрации;
  • сведения о последней активности;
  • технический статус аккаунта в ValutBot.

Telegram ID используется как основной технический идентификатор аккаунта внутри ValutBot.

ValutBot не получает номер телефона пользователя через обычное взаимодействие с ботом, если пользователь самостоятельно не передал его Сервису посредством отдельной функции Telegram.

2. Настройки и данные функций ValutBot

Для предоставления основных функций Сервис хранит настройки и данные, создаваемые при использовании ValutBot.

В зависимости от используемых функций они могут включать:

  • выбранные валютные и криптовалютные пары;
  • выбранную криптовалютную биржу или источник данных;
  • параметры отслеживания курса;
  • исходные и целевые значения;
  • настройки уведомлений;
  • состояние срабатывания уведомлений;
  • настройки отчётов;
  • периодичность, день и время отправки;
  • язык и часовой пояс;
  • другие технические параметры, необходимые для работы выбранных пользователем функций.

Эти данные используются для сохранения настроек пользователя, отслеживания курсов, отправки уведомлений и предоставления других запрошенных функций ValutBot.

3. История уведомлений и курсов

Для работы уведомлений, отчётов и связанных функций ValutBot может хранить сведения о:

  • срабатываниях уведомлений;
  • соответствующей подписке пользователя;
  • времени события;
  • значениях курсов, необходимых для работы уведомлений и формирования отчётов.

Эти данные используются для функционирования Сервиса и предоставления соответствующих пользовательских функций.

4. Premium, промокоды и бонусы

Если пользователь использует Premium, промокоды или участвует в бонусных программах, ValutBot может хранить сведения о:

  • наличии и сроке действия Premium;
  • начале и окончании периода Premium;
  • факте предоставления Premium ранее;
  • применённых промокодах;
  • партнёрских предложениях;
  • пробных периодах;
  • бесплатных Premium-бонусах;
  • технических состояниях, необходимых для предоставления Premium и связанных функций.

Эта информация используется для предоставления оплаченных и бесплатных возможностей, определения доступных пользователю предложений и предотвращения ошибочного или повторного предоставления ограниченных бонусов.

5. Платежи

При совершении покупки ValutBot может обрабатывать техническую информацию о платеже, необходимую для подтверждения покупки и предоставления соответствующей услуги.

Такая информация может включать:

  • идентификатор пользователя;
  • идентификатор и технические параметры счёта;
  • сумму;
  • валюту или используемую платёжную единицу;
  • способ оплаты;
  • идентификатор платёжной операции;
  • применённый промокод;
  • дату и состояние операции.

Оплата внутри Telegram может осуществляться с использованием Telegram Stars и платёжной инфраструктуры Telegram.

ValutBot не получает данные банковской карты пользователя в рамках обычной оплаты через Telegram Stars.

Неоплаченные технические счета хранятся ограниченное время. Просроченные неоплаченные счета автоматически удаляются после 24 часов.

Информация о завершённых платежах может сохраняться после удаления аккаунта в объёме, необходимом для финансового и технического учёта, разрешения платёжных споров и выполнения применимых юридических, бухгалтерских или налоговых обязанностей.

При удалении аккаунта непосредственная связь сохранённой платёжной записи с профилем ValutBot удаляется в соответствии с технической реализацией Сервиса.

6. Реферальная система и партнёрские предложения

При использовании соответствующих функций ValutBot может обрабатывать:

  • информацию о способе первого открытия Сервиса;
  • сведения о реферальном приглашении;
  • идентификаторы, необходимые для определения связи между пригласившим и приглашённым пользователями;
  • применённый промокод;
  • источник или партнёрское предложение;
  • сведения, необходимые для определения права на соответствующий бонус.

Эти данные используются для работы реферальных, промокодных и партнёрских функций и предотвращения злоупотреблений ими.

7. Аналитика использования

ValutBot собирает ограниченную внутреннюю аналитику использования Сервиса для понимания работы функций, обнаружения проблем и улучшения продукта.

Она может включать:

  • факт использования определённой функции;
  • действия внутри интерфейса;
  • название экрана или функции;
  • время события;
  • технический идентификатор пользовательской сессии;
  • ограниченные технические параметры соответствующего события.

ValutBot не предназначен для сохранения произвольного текста сообщений пользователя в продуктовой аналитике.

Индивидуальные аналитические события хранятся не более 180 дней, после чего удаляются в рамках автоматической очистки.

При удалении аккаунта связанные с ним индивидуальные аналитические события удаляются независимо от истечения указанного срока.

На основе индивидуальных событий может формироваться агрегированная статистика, например об общем количестве использований определённой функции. Если такая статистика больше не содержит Telegram ID или иного идентификатора конкретного пользователя, она может сохраняться после удаления аккаунта.

8. Техническая доставка сообщений

Для надёжной доставки уведомлений и других сообщений ValutBot может временно хранить техническую очередь сообщений.

Она может содержать:

  • Telegram ID получателя;
  • техническое содержимое задания на отправку;
  • состояние доставки;
  • сведения об ошибке доставки;
  • идентификатор отправленного Telegram-сообщения;
  • время создания и обработки задания.

Эти данные используются для доставки сообщений и диагностики технических проблем.

Связанные с пользователем записи очереди удаляются при удалении аккаунта.

9. Защита бесплатных Premium-бонусов от повторного получения

Некоторые бесплатные Premium-бонусы ValutBot предназначены для однократного использования.

Для предотвращения повторного получения таких бонусов посредством удаления и повторного создания аккаунта ValutBot сохраняет ограниченный технический признак использования соответствующего бонуса.

Для его создания Telegram ID преобразуется с использованием криптографического HMAC и секретного серверного ключа. Исходный Telegram ID в этой записи не хранится.

Запись может содержать:

  • псевдонимизированный технический идентификатор;
  • тип или программу использованного бонуса;
  • дату его получения;
  • дату окончания срока хранения записи.

Она не содержит имени, username, настроек ValutBot, валютных подписок, истории уведомлений или истории использования аккаунта.

Эта информация используется исключительно для определения того, был ли соответствующий одноразовый бесплатный Premium-бонус уже использован.

Технический признак хранится не более 24 месяцев, после чего подлежит автоматическому удалению.

Поскольку технически возможно сравнить вновь вычисленное значение с ранее сохранённым, ValutBot рассматривает этот идентификатор как псевдонимизированную, а не полностью анонимную информацию.

10. Цели обработки данных

В зависимости от категории ValutBot обрабатывает данные для:

  • создания и обслуживания аккаунта;
  • сохранения пользовательских настроек;
  • отслеживания выбранных курсов;
  • отправки уведомлений и отчётов;
  • предоставления Premium;
  • обработки и подтверждения покупок;
  • работы реферальных, бонусных и партнёрских программ;
  • предотвращения повторного получения одноразовых бонусов;
  • обеспечения безопасности и стабильности Сервиса;
  • доставки сообщений;
  • диагностики ошибок;
  • анализа использования функций и улучшения ValutBot;
  • разрешения платёжных и иных споров;
  • выполнения применимых юридических обязанностей.

ValutBot не продаёт персональные данные пользователей.

11. Правовые основания обработки

В зависимости от цели обработка персональных данных может осуществляться на следующих основаниях:

Исполнение договора или действия по запросу пользователя. Это относится, например, к созданию аккаунта, сохранению настроек, отслеживанию курсов, отправке уведомлений, предоставлению Premium и обработке покупки.

Законный интерес. ValutBot может обрабатывать ограниченные данные для обеспечения безопасности и стабильности Сервиса, предотвращения злоупотреблений, диагностики технических проблем и анализа использования функций, если интересы или основные права пользователя не имеют преимущественной силы.

Юридическая обязанность. Некоторые данные, в частности связанные с платежами, могут обрабатываться или сохраняться, если это необходимо для выполнения применимых требований законодательства.

Согласие. Если для конкретной обработки применимое законодательство требует согласия, такая обработка осуществляется на основании согласия пользователя.

12. Инфраструктура и сторонние сервисы

Telegram

ValutBot использует Telegram как платформу взаимодействия с пользователями и доставки сообщений.

Telegram является самостоятельным сервисом и обрабатывает определённую информацию в соответствии со своими условиями и политикой конфиденциальности.

Railway

Для размещения и технической работы ValutBot используется облачная инфраструктура Railway.

Данные, необходимые для работы ValutBot, могут обрабатываться и храниться на инфраструктуре Railway в объёме, необходимом для предоставления Сервиса.

Источники финансовых данных

Для получения курсов и другой финансовой информации ValutBot использует внешние источники, в том числе:

  • Binance;
  • Bybit;
  • KuCoin;
  • Центральный банк Российской Федерации;
  • Frankfurter;
  • open.er-api.

Эти сервисы используются для получения финансовых данных.

При обычном запросе курса ValutBot не передаёт этим источникам Telegram ID, username, отображаемое имя или другие идентификаторы конкретного пользователя. Запрос содержит только информацию, необходимую для получения соответствующих финансовых данных, например требуемую валютную или криптовалютную пару.

Используемые поставщики инфраструктуры и источники данных могут изменяться по мере развития ValutBot.

13. Международная обработка данных

Используемые ValutBot сторонние поставщики могут иметь инфраструктуру или осуществлять обработку данных в разных странах.

Если персональные данные передаются за пределы юрисдикции пользователя или Европейской экономической зоны и применимое законодательство требует специальных гарантий такой передачи, должны использоваться предусмотренные законодательством механизмы защиты.

Внешним источникам финансовых данных, перечисленным в разделе 12, при обычном получении курсов персональные идентификаторы пользователя не передаются.

14. Сроки хранения

ValutBot не хранит персональные данные дольше, чем это необходимо для соответствующей цели.

Основные данные аккаунта и пользовательские настройки обычно хранятся до удаления аккаунта пользователем или возникновения иной законной причины для их удаления.

Для отдельных категорий действуют специальные сроки:

  • индивидуальные события продуктовой аналитики — не более 180 дней;
  • просроченные неоплаченные счета — 24 часа;
  • псевдонимизированный технический признак использования бесплатного Premium-бонуса — не более 24 месяцев.

При удалении аккаунта связанные с ним данные, подлежащие удалению, удаляются независимо от обычного максимального срока их хранения.

Записи о завершённых платежах могут храниться дольше, если это необходимо для выполнения применимых юридических, бухгалтерских или налоговых обязанностей либо разрешения споров.

Агрегированная статистика, которая больше не позволяет ValutBot идентифицировать отдельного пользователя, может храниться без привязки к сроку существования аккаунта.

15. Удаление аккаунта

Пользователь может удалить аккаунт непосредственно средствами ValutBot.

Перед окончательным удалением Сервис сообщает пользователю о последствиях этого действия.

После подтверждения удаляются связанные с аккаунтом:

  • профиль пользователя;
  • настройки;
  • созданные уведомления и подписки;
  • пользовательские отчёты;
  • реферальные связи;
  • индивидуальная аналитика;
  • история срабатываний уведомлений и связанные пользовательские данные курсов;
  • ожидающие неоплаченные счета;
  • технические задания на доставку сообщений;
  • другие данные, которые согласно технической реализации должны существовать только вместе с аккаунтом.

Удаление этих данных является необратимым.

После удаления могут сохраняться только ограниченные категории информации, для которых существует отдельная цель хранения:

  • псевдонимизированный технический признак использованных бесплатных Premium-бонусов — не более 24 месяцев;
  • необходимые записи о завершённых платежах;
  • агрегированная статистика, больше не связанная с идентификатором пользователя.

16. Права пользователя

В случаях, предусмотренных применимым законодательством, пользователь может иметь право:

  • получить информацию об обработке своих персональных данных;
  • получить доступ к своим данным;
  • потребовать исправления неточных данных;
  • потребовать удаления данных;
  • потребовать ограничения обработки;
  • возразить против определённых видов обработки;
  • получить данные в переносимом формате, если соответствующее право применимо;
  • отозвать ранее предоставленное согласие, если обработка основывается на согласии;
  • обратиться с жалобой в компетентный орган по защите персональных данных.

Некоторые из этих прав могут иметь предусмотренные законодательством ограничения.

Удаление аккаунта непосредственно через ValutBot не лишает пользователя возможности обратиться по вопросам обработки данных отдельно.

17. Запросы пользователя

По вопросам обработки персональных данных и реализации соответствующих прав пользователь может обратиться по адресу:

legal@valutbot.com

Для предотвращения несанкционированного доступа к чужим данным ValutBot может запросить разумное подтверждение того, что обращающийся пользователь является владельцем соответствующего Telegram-аккаунта.

Запрашиваются только данные, необходимые для такой проверки.

18. Безопасность

ValutBot принимает разумные технические и организационные меры для защиты данных от несанкционированного доступа, изменения, утраты или раскрытия.

В частности, для технического признака использования бесплатных Premium-бонусов применяется HMAC с секретным серверным ключом, благодаря чему непосредственно Telegram ID в соответствующей записи не сохраняется.

Доступ к данным ограничивается в соответствии с технической необходимостью.

При этом ни одна информационная система не может гарантировать абсолютную безопасность.

19. Изменения Политики конфиденциальности

Настоящая Политика может периодически обновляться в связи с развитием ValutBot, изменением способов обработки данных, используемой инфраструктуры или применимого законодательства.

На странице Политики указывается дата последнего обновления.

При существенных изменениях ValutBot может дополнительно уведомить пользователей через Сервис.

Если уведомление или получение нового согласия требуется применимым законодательством, соответствующие действия осуществляются в установленном законом порядке.
